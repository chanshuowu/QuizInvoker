Qui trovi aiuto per aggiungere domande, condividere file e ripassare con la tua raccolta.

Contatta l’assistenza

Per chiedere aiuto, inviare commenti o suggerire una funzione, scrivi a chanshuowu@icloud.com.

Se hai un problema, indica il modello del dispositivo, la versione di iOS, la versione di Quiz Invoker e i passaggi per riprodurlo. Rimuovi i dati privati degli studenti da schermate e file prima di inviarli.

Aggiungi e controlla le domande

Puoi partire da foto, PDF, documenti o dai tuoi appunti.

  1. Apri «Aggiungi domande», seleziona il materiale e controlla le istruzioni. Tocca «Condividi con l’IA» e scegli un’app di IA esterna compatibile per preparare le domande.
  2. Condividi il file risultante con Quiz Invoker o apri un file salvato con «Importa» nella raccolta. Se il risultato è in formato testo, scegli «Importa → Incolla i risultati dell’IA» e incolla il blocco completo.
  3. «Rivedi prima» lascia in attesa le nuove domande per il controllo. «Accetta subito» le salva se c’è spazio. Le domande accettate sono disponibili per il ripasso.

Problemi di condivisione o importazione

Se l’app di IA non compare nel menu di condivisione di iOS, salva il file in File e allegalo dall’app stessa. Se non accetta file ZIP, usa «Copia le istruzioni», allega il materiale manualmente e importa l’intero risultato testuale con «Incolla i risultati dell’IA». Un link alla conversazione non si può importare come una raccolta di domande.

Per spiegazioni, suggerimenti o un test su domande già salvate, scegli «Impara con l’IA». La conversazione prosegue nell’app esterna, che può richiedere un account o un abbonamento.

Ripassa offline

Tocca «Studia» per esercitarti offline con le domande accettate. Prova a rispondere, mostra la risposta e scegli «Corretto» o «Riprova». Puoi fare una pausa e riprendere in seguito. Usa «Imposta il focus di studio» nella raccolta per scegliere che cosa ripassare.

Crea e ripristina un backup

Usa «Impostazioni → Trasferimento e backup → Crea backup» per salvare una copia della raccolta e dei dati di studio. Esporta separatamente le domande in attesa. «Ripristina da backup» sostituisce i dati salvati dopo la conferma. Conserva il codice del backup, perché Quiz Invoker non può recuperarlo.
